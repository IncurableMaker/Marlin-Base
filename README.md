## Marlin - Arnie Version

**Not for production use. Use with caution!**
This is a version of Marlin configured for a specific printer built for use in schools.  The plans will be mad available at some point and will be linked here.  The basic design is a Corexy using an FYSETC F6 board and TMC-driven steppers.  
At the moment this is very much in the experimental stage, but further down the line, the aim is to have a robust printer and firmware that is tough enough for a school environment and can be built and maintained by teachers and pupils.
